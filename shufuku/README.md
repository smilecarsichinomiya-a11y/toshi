# 修復歴チェッカー

膜厚・ボルト・骨格の写真から、**修復歴の「疑い」**を見つける補助アプリです(スマホのブラウザで動きます)。
AIは「何が見えるか」を観察するだけで、疑い度はルールで計算します。修復歴の最終判断は必ず現物で行ってください。

## はじめかた
1. Python を入れる(https://www.python.org/downloads/ 。Windows は「Add python.exe to PATH」にチェック)
2. `.env.example` をコピーして `.env` にし、`ANTHROPIC_API_KEY=` の後ろにキーを貼る(無くても動きます)
3. `start_windows.bat`(Windows)か `start_mac.command`(Mac)をダブルクリック
4. 黒い画面に出る「スマホで開く」のアドレスを、**同じWi-Fiのスマホ**で開く

## 診断の流れ
① 車の情報 → ② 膜厚入力(厚い所は自動で色が変わる) → ③ ボルト・骨格を撮影(AI判定。怪しければ次に撮る場所を自動案内) → ④ 目視チェック → ⑤ 結果とコピー用メモ

- 左右ペアで撮影し、AIに見比べさせます。写真が不鮮明なら撮り直しを指示します
- AIと違うと思ったら「あなたの目での判定」が優先されます
- 結果は「疑いが強い / 可能性あり / 根拠は少ない / 判定保留(確認不足)」で表示。「修復歴あり」とは断定しません
- 診断データはスマホ(ブラウザ)内に保存。写真はAI判定のときだけ Anthropic に送られ、サーバーには残りません

## 注意
- 同じWi-Fi内でしか使えません。外から使う場合は、HTTPSで公開し `SHUFUKU_ACCESS_CODE` を必ず設定してください
- 膜厚のしきい値は `.env` か、画面の「車の情報」で変えられます
- テスト: `pip install -r requirements.txt && python -m pytest tests`
