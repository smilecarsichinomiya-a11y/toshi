## A. 法律・実務の事実

### A1. 慰謝料請求の根拠・要件・請求先・求償
【確認済み】
- 不貞行為は民法770条の離婚原因に関わる概念で、「配偶者以外との自由意思に基づく肉体関係」と説明される。請求には不貞の証拠、不貞と婚姻関係への損害の因果、自由意思が挙げられる。 https://www.ben54.jp/column/divorce/220 (検索要約。条文自体は未確認)
- 請求先は配偶者・不倫相手の双方が可能で、離婚しなくても不倫相手のみに請求できる。 https://www.ben54.jp/column/divorce/1183 / https://www.bengo4.com/c_3/guides/furin-aite-isharyo-seikyu/
- 最高裁平成31年2月19日第三小法廷判決(民集73巻2号187頁): 不貞相手は、特段の事情がない限り「離婚そのもの」による慰謝料(離婚慰謝料)の賠償義務を負わない。不貞慰謝料(不貞行為自体の損害)とは区別される。 https://www.mc-law.jp/rikon/27534/ (判例研究: https://mu.repo.nii.ac.jp/record/1462/files/musashinohogaku14_02.pdf)
- 不貞当事者2名の賠償債務を不真正連帯債務とし、一方が負担部分を超えて支払うと求償が問題になる、とした下級審の判断が紹介されている(最高裁ではない)。出典は上記判例研究群(fukuoka-u.repo.nii.ac.jp/record/4855/files/J6403_0693.pdf)。
- 書面で請求した場合、内容証明などは記録が残る。 https://www.ben54.jp/column/divorce/220

【仮説(要検証)】
- 根拠条文は民法709条(不法行為)・710条(非財産的損害)、共同不法行為は719条、と一般に説明される。検索結果では条文番号の本文確認ができていない。e-Govで確認すること。
- 求償の仕組み(不倫相手が全額支払った後に配偶者へ負担部分の請求ができる、示談で求償放棄条項を入れることがある)の具体的な説明ページは未確認。商品では「求償される可能性がある。示談時は弁護士に条項を確認」程度に留めるのが安全。
- 「婚姻破綻していたと信じた理由の検討を求め賠償命令を破棄」という最高裁報道(秋田魁新報 2026-06-05付、タイトルのみ確認) https://www.sakigake.jp/news/article/20260605CO0129/ 。要件(故意過失・婚姻破綻の抗弁)の最新動向に関わる可能性があるが、本文未確認。必ず原典を確認し、確認前は商品に書かない。

【不明】
- 上記最高裁報道の事件番号・判示範囲。

### A2. 消滅時効
【確認済み】
- 不貞慰謝料: 「損害および加害者を知った時から3年」「不法行為の時から20年」のいずれか早い方。根拠は民法724条。 https://www.daylight-law.jp/divorce/qa/qa111/ / https://lifestyle.assist-all.co.jp/?p=28241
- 起算点の争点: 相手の氏名・住所が分からない段階で3年が進むか等は個別判断。 https://www.bengo4.com/c_3/c_1001/c_1350/m_259974/
- 離婚慰謝料は不貞慰謝料と別の請求で、離婚成立から3年とする理解が相談サイトで紹介されている(弁護士ドットコム相談、https://www.bengo4.com/c_3/c_1321/bbs/%E9%9B%A2%E5%A9%9A%E5%BE%8C+%E6%85%B0%E8%AC%9D%E6%96%99%E8%AB%8B%E6%B1%82+%E6%99%82%E5%8A%B9/)。
- 内容証明・訴訟提起で時効完成が猶予されるとの説明あり(盗撮事案解説の一般論、https://www.ben54.jp/column/crime/1130)。

【仮説(要検証)】
- 継続的不貞では行為ごと・「不貞関係を知った時」など起算点の捉え方が複数あり得る。商品では「不貞の事実と相手を知った日を記録し、3年を目安に早めに弁護士へ」とし、断定しない。
- 時効の猶予・更新の正確な手段(催告は6か月の猶予のみ、等)は未確認。

### A3. 慰謝料の相場
【確認済み】(いずれも法律事務所サイトの目安で、算定基準は明確でない)
- 離婚に至った場合 100万〜300万円程度 / 離婚しない場合は低め。 https://www.ben54.jp/column/divorce/1183
- 別の事務所: 離婚する場合 約200〜300万円、しない場合 約50〜100万円。 https://www.daylight-law.jp/divorce/70001/isyaryosouba/
- 総括的な説明: 約50万〜300万円の幅。 https://www.ben54.jp/column/divorce/1199 (検索要約)
- 増減要因: 婚姻期間、不貞の期間・回数、子の有無、悪質性、被害の大小、加害者の収入・資産。 https://www.mc-law.jp/rikon/20019/
- 訴訟では弁護士費用相当額が認容額の約10%上乗せされることが多いとの説明。 https://www.bengo4.com/c_3/c_1001/c_1350/m_214889/

【仮説】
- 事務所ごとに幅が異なるため、商品では「50万〜300万円程度の幅で、個別事情により上下」と書き、司法統計等の一次データは未確認と明記する。

【不明】
- 裁判所公表の統計・裁判例集計に基づく相場。

### A4. 証拠
【確認済み】
- 評価されやすいとされるもの: ホテル出入り等の写真・動画、メールやLINEで肉体関係が推認できる内容、クレジットカード明細、通話履歴等。 https://www.avance-lg.com/customer_contents/rikon/saretsuma/ / https://adv-isharyou.jp/column/column_23
- 弱いもの: 親密な様子だけ・ハートの絵文字等の日常的やり取り、問い詰めて得た自白(後に「その場をおさめるため」と否定されやすい)。 https://adv-isharyou.jp/column/column_23 / https://allabout.co.jp/gm/gc/484173/ (検索要約)
- LINEトークが削除されていても、バックアップ・他端末・交通機関やホテル履歴等を組み合わせる実務。画面は撮影して残す方が「編集した」と主張されにくいとの解説。 https://minami.law/(不貞行為とLINE解説)
- 違法収集リスク: スマホ内のメールを見る行為は「電気通信回線を通じて」要件に当たらないとの見解があるが、態様によっては不正アクセス禁止法の問題。GPSアプリを相手端末に無断で仕込むと不正指令電磁的記録供用罪(刑法168条の2第2項)の解説あり。車両へのGPS無断設置は迷惑防止条例・ストーカー規制法の問題となり得る。 https://www.mc-law.jp/kigyohomu/2640/ / https://www.ben54.jp/column/crime/1032
- 民事では違法収集でも直ちに証拠能力が否定されるわけではないが、人格権を著しく侵害する方法は除外され得る。東京地裁平成25年10月9日判決はGPS情報の証拠能力を認めた例として紹介。 https://www.ben54.jp/news/1955 ほか
- 探偵のGPS調査で相当範囲を逸脱すると民事上の不法行為が成立し得るとの裁判紹介あり。 https://www.ben54.jp/news/1955

【仮説】
- 「違法でも民事では使えることがある」は読者が誤解しやすい。商品では「使える可能性」ではなく「自分が訴えられる・刑事責任を負うリスク」を前面に出し、ログイン・無断インストール・GPSは「やらない」と明記するのが安全。

### A5. 離婚の流れ・婚姻費用・財産分与・親権・有責配偶者
【確認済み】
- 流れ: 協議 → 調停(裁判官1名+調停委員2名) → 審判/訴訟。夫婦関係調整調停(離婚)は親権・面会交流・養育費・財産分与等を扱い、別居中の生活費は婚姻費用分担調停(審判)で別に決める。調停成立日を含め10日以内に離婚届提出。 https://www.courts.go.jp/utsunomiya/vc-files/utsunomiya/2024/flow_huuhukannkei_R6060.pdf
- 財産分与の裁判所案内あり(仙台家裁)。 https://www.courts.go.jp/sendai/saiban/zaisanbunyo/index.html
- 有責配偶者の離婚請求: 最高裁大法廷昭和62年9月2日(民集41巻6号1423頁)。(1)長期間の別居、(2)未成熟子の不存在、(3)相手方が極めて苛酷な状態に置かれない、を考慮して例外的に認める。別居10年程度が目安とされてきたが一律ではなく、未成熟子の存在だけで否定されない(平成6年最高裁)。 https://www.mc-law.jp/rikon/28550/ / 裁判所判例ページ https://www.courts.go.jp/hanrei/55213/detail2/index.html
- 改正民法(令和6年法律第33号)が2026年4月1日施行。離婚後の共同親権の選択、養育費・親子交流の見直し。協議が原則で、合意できなければ家裁が判断、DV・虐待のおそれ等は単独親権。 https://www.city.kumamoto.jp/kiji00366423/index.html (自治体が法務省パンフ参照を案内) / https://column.itojuku.co.jp/shihoshoshi/basic/kyoudoushinken/

【仮説(要検証)】
- 法定養育費制度の新設・財産分与の請求期間延長は二次情報(https://office-tree.jp/blog/divorce/joint-custody-2026/)のみ。法務省パンフで確認するまで具体数値は書かない。
- 養育費・婚姻費用の算定(算定表)は今回未確認。商品では「裁判所の算定表がある、金額は弁護士・調停で確認」止まりにする。
- 「不倫した側が悪い=有責側から請求できない」ではなく、有責配偶者の請求は例外要件つき、という点を、サレ側の読者向けに平易化する。

### A6. 別居・家計
【確認済み(相談・コラム水準)】
- 住宅ローンは共有名義・連帯保証などの形があり、離婚時に名義変更・債務解消は容易でない。別居後のローン返済分が財産分与で考慮され得る。婚姻費用の住居費にローンが含まれることがある。 https://www.daylight-law.jp/divorce/qa/qa201 / https://www.bengo4.com/c_3/c_1150/bbs/%E5%88%A5%E5%B1%85+%E4%BD%8F%E5%AE%85%E3%83%AD%E3%83%BC%E3%83%B3/
- 基準時(ローンは別居時、不動産価値は離婚時か)は相談掲示板上の「疑問」であり、確定回答ではない。

【仮説】
- 別居前に、通帳・保険(解約返戻金)・ローン残高・名義・連帯保証を資料化しておくと有用。生命保険・学資保険・預貯金の分与扱いは今回未確認。ただし「資料を写真で残す」程度の実務ポイントは弁護士相談の準備として妥当と考えるが要検証。
- 「家を出ると不利になるか」は未確認。断定せず「出る前に弁護士へ」と書く。

【不明】
- 財産分与の基準時の一次情報、保険の取扱い。

### A7. 誓約書・示談書・公正証書
【確認済み】
- 配偶者との再構築は誓約書、不倫相手との清算は示談書、という使い分けが実務上一般的(法的な決まりはない)。 https://www.bengo4.com/c_3/guides/furin-seiyakusho/
- 示談書は民法695条の和解契約。清算条項・口外禁止・違約金・接触禁止が典型。分割払いや高額の場合、強制執行認諾文言付き公正証書が回収の安全策。 https://office-tree.jp/blog/legal-documents/jidansho-creation-guide/
- 違約金が高すぎると争われた例、「脅迫された」と無効主張された例、署名を急かされた例が相談サイトにある。 https://www.bengo4.com/c_3/c_1001/m_975846/ / https://www.bengo4.com/c_3/c_1001/bbs/%E4%B8%8D%E5%80%AB+%E7%A4%BA%E8%AB%87%E5%BE%8C+%E9%81%95%E7%B4%84%E9%87%91/
- 不貞発覚後に「許す」とLINEや口頭で伝えた場合の慰謝料請求への影響は論点になる(弁護士ドットコム記事)。 https://www.bengo4.com/c_3/c_1001/c_1350/m_1067955/ (検索要約。結論は未確認)

【不明】
- 求償権放棄条項の解説ページ、違約金額の有効範囲(検索では見つからず)。

## B. 競合調査
【確認済み】
- note上で『浮気 不倫 発覚後 チェックリスト/証拠/サレ妻』系の有料記事・マガジンは、今回の検索では見つからなかった(WebSearchはnote内の価格・スキ数・購入数を拾えない)。無料の体験記系は存在: 「不倫発覚から離婚までの経緯|自力探偵サレ山」 https://note.com/jirikitantei/n/n339dc4f2de99 (有料かは未確認)。
- 無料の強力な代替: 法律事務所の「サレ妻」解説群(デイライト、ベリーベスト、アディーレ等)が手順(証拠→話し合い→慰謝料請求)、兆候チェックシートまで無料提供。 https://www.daylight-law.jp/divorce/qa/saretsuma/ / https://rikon.vbest.jp/columns/8129/ / https://www.daylight-law.jp/divorce/70001/choukou/
- 無料記事の共通型: 証拠確保 → 感情的に問い詰めない → 離婚か再構築か → 慰謝料請求 → 弁護士相談。

【不明】
- 有料商品の価格帯、構成、スキ数・購入数、レビュー不満点。Brain等も未検出。
- 実施方法の提案(非WebSearch): noteのハッシュタグ・検索画面を人手で確認し、価格・スキ数・目次を10件程度スクショ。

【仮説】
- 無料の弁護士記事が充実しているため、「情報」だけでは差別化できない。有料の価値は「記入して使える形式」「時系列に並べた行動手順」「やってはいけない行動の判断基準」にある。

## C. 読者の悩みの具体語
注記: 以下のうち(a)は掲示板の質問文そのもの(または検索結果のタイトル)、(b)は相談タグ・URL由来の語や検索要約中の質問の言い換え。実在の相談文を20個正確に引用する目標は、接続制約のため(a)8件前後で未達。残りは(b)として区別して記載。

## D. 差別化案
【仮説(要検証。以下は設計案であり、効果の数値根拠はない)】
競合の穴(無料の法律事務所記事が弱い領域)
1. 「記入して使える」形式の欠如。無料記事は文章解説中心。
2. 発覚直後の30日を日付順に並べた行動設計。
3. 「やってはいけない」判断基準(無断ログイン、GPS、SNS暴露、署名を急かされた示談)を一枚で見られる形。
4. 感情面(睡眠・食事・誰に話すか)と手続面の同居。
5. 再構築を選ぶ人向けの情報(誓約書の項目、許すと言う前に確認すること)が少ない。
6. 探偵・弁護士の選び方(見積もり確認項目、成功報酬の返金条件)。

追加要素案
- 記録シート: 発覚日、不貞を知った日、相手を知った日(時効の目安メモ)、証拠の保管場所、やり取りの日時(感情ではなく事実のみ)。
- 弁護士相談前の準備シート: 時系列メモ、家族構成、収入・財産・ローン一覧、証拠リスト、「聞きたい5つ」質問欄、希望(離婚/再構築/慰謝料のみ)。
- 家計の棚卸し表: 預貯金、保険(解約返戻金)、ローン名義・連帯保証、別居後の生活費試算。
- 証拠のセルフチェック: 「肉体関係を推認できるか」「合法的に入手したか」の2軸。
- 探偵見積もりチェック欄: 総額・延長・成功の定義・返金条件・契約書面。
- 感情整理ワーク: 「今決めなくていいこと」リスト、1週間・30日・90日で決めることの仕分け。
- 相談窓口一覧(法テラス、よりそいホットライン、188。基準・番号は公式で確認の注記つき)。
- 再構築用誓約書の項目チェック(ひな形は付けず、項目の一覧のみ。弁護士確認を促す)。
