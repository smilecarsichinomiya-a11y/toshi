# toshi — Claude が判断する日本株デイトレード(仮想売買)

**証券口座は使いません。** 無料・登録不要の株価データ(Yahoo Finance)を使い、Claude が売買を判断して
**仮想のお金(既定300万円)で自動売買**し、毎日その成績を検証・蓄積します。実際のお金は一切動きません。

```
Yahoo(5分足・日足, 約20分遅れ) ─▶ 指標(VWAP・寄り付きレンジ・RSI…) ─▶ Claude ─▶ リスク管理 ─▶ 仮想売買
                                          ▲ 教訓                              │ 強制: 損切り・利確・15:15全決済
                                          │                                   ▼
                         Claude振り返り ◀─ 日次成績集計(15:40) ◀─ SQLite ─▶ ダッシュボード(ブラウザ)
                                                 └─▶ data/reports/日付.json, daily_stats.csv
```

## はじめかた

```bash
pip install -r requirements.txt
cp .env.example .env          # ANTHROPIC_API_KEY を書き込む
python -m toshi               # ブラウザで http://127.0.0.1:8000 を開く
```

- 平日 9:00〜15:40 に PC を起動したまま `python -m toshi` を動かしておく必要があります(スリープすると止まります)。
- API キーが無い場合は、単純なルール(VWAP・寄り付きレンジ)で売買します。
- ネット接続なしで画面を試すだけなら `TOSHI_DATA=synthetic`(ダミー株価)を使います。
- テスト: `python -m pytest`

## 売買スタイル (スキャルピングではなくデイトレード)

| 項目 | 設定 | 意味 |
|---|---|---|
| 判断の間隔 | 15分ごと | 数分単位の値動きは狙わない(データが約20分遅れるため) |
| 狙い | 1回 +2〜3%、保有30分〜数時間 | その日のトレンドに乗る |
| 新規の買い | 9:30〜14:30 | 寄り付き直後の乱高下と大引け前は避ける |
| 全決済 | 15:15 | 翌日に持ち越さない |
| 損切り / 利確 / トレーリング | -1.5% / +3% / 高値から-1.5% | Claude の判断に関係なく機械的に実行 |
| 回数制限 | 1日20注文、同じ銘柄の往復は2回、決済後30分は同じ銘柄を買わない | 売買のしすぎを防ぐ |
| その他 | 最大3銘柄、1銘柄は資産の33%まで、1日-2%で新規買い停止、空売りなし | |
| 遅延データ | 最新の足が45分以上古い銘柄は新規の買いをしない | データ不具合への備え |

## 成績検証 (毎日自動)

- 毎営業日 **15:40** に集計します。PC を止めていた日があっても、次回起動時に**未集計の日をすべて集計**します。
- **日次**: 損益・騰落率、取引数、勝率、PF(総利益÷総損失)、平均の勝ち額・負け額、最大ドローダウン、平均保有時間、TOPIX 比較。決済理由別・銘柄別・時間帯別の内訳もあります。
- **累計**: 検証日数、勝ち日数、累計損益、平均日次リターン、取引勝率、PF、最大ドローダウン、シャープレシオ。
- **振り返り**: Claude が勝因・敗因と「翌日以降の教訓」(最大5個)を書き、**直近5日分の教訓を毎回の売買判断に渡します**。
- **保存先**: `data/toshi.db`、`data/reports/日付.json`(全取引つき)、`data/reports/daily_stats.csv`(Excel で開けます)。
  `data/` フォルダは git に含まれないので、ときどきバックアップしてください。

## 知っておくべき限界

- **仮想売買の成績は、実際の売買より良く見えがちです。** 遅れた株価でそのまま約定した扱いにしていて、板の厚さや約定しないリスクを考慮していないためです(スリッページは0.05%で近似)。
- Yahoo のデータは遅延・欠損があり得ます。非公式な取得方法のため、仕様変更で取得できなくなる可能性もあります。
- 祝日・年末年始は考慮していません(データが無いので何もしません)。
- **このシステムの成績は将来の利益を保証しません。**

